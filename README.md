# codex-auto

Reusable AI-assisted software engineering governance and orchestration protocol.

This repository defines a project-agnostic workflow in which a lead/reviewer agent plans and verifies work, an implementation agent executes bounded tasks, GitHub records the shared state, CI provides machine-verifiable evidence, and a human retains merge authority.

The initial protocol is being developed through a feature branch and pull request so that this repository follows its own governance model from the start.
